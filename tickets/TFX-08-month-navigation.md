# TFX-08 — Month navigation on the VAT return

Needs `/spec TFX-08` before build. Split out of TFX-06.

## Problem
The VAT return shows one month at a time (`/filing/YYYY-MM`). Testers can only reach other months by editing the URL, so they cannot check or file earlier months.

## Acceptance idea
- [ ] Previous/next month links on the VAT return move between periods without editing the URL.
